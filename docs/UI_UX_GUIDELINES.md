# UI/UX Guidelines — LegalIntern

## 1. Visual Language & Color Palette

- **Primary Navy:** `#14243A` — Serious, established, authoritative legal tone.
- **Deep Navy:** `#0F172A` — Contrast headers, high-emphasis containers.
- **Background:** `#F7F9FC` — Clean, soft off-white surface minimizing eye fatigue.
- **Surface:** `#FFFFFF` — Cards, modals, chat bubbles.
- **Primary Teal:** `#0F766E` & `#14B8A6` — Brand accent, interactive CTAs, verified badges.
- **Text:** `#172033` (main text), `#64748B` (muted metadata).
- **Borders:** `#E2E8F0` — Subtle division lines.

## 2. Typography

- **Font:** Geist Sans & System UI fallbacks.
- **Weights:** Regular (400) for body, Semibold (600) for labels, Bold/Extrabold (700/800) for headings.

## 3. Desktop 3-Panel Workspace

- **Left Panel (260–280px):** Case metadata, active character switcher, stage indicator, progress tracker.
- **Center Panel (Flexible):** AI chat conversation log, character identity header, multiline composer supporting Enter to send and Shift+Enter for newlines.
- **Right Panel (320–360px):** Evidence exhibition cards, modal inspection with full text & reliability notes, private student investigative notes with autosave.

## 4. Mobile Responsiveness

- Transitions from a 3-column layout into dedicated tabbed views: **Suhbat (Chat)**, **Ish holati (Overview)**, and **Dalillar (Evidence)**.
- Full touch targets (min 44px) and zero horizontal overflow.
